# 长音频 STT 连续语音与交互验收

日期：2026-10-04。范围更新：按用户最新要求，以 SenseVoice 主体逻辑为重点，Whisper 优化与候选复测暂缓。未执行项不计为通过。

后续已完成八种因素组合的退化定位和六十五处切点试听包，见 [SenseVoice 边界诊断](stt-sensevoice-boundary-diagnosis.md)。本报告保留本验收轮次的测试计数与原始记录；最新测试计数见后续报告。生产默认仍未改变。

## 配置与架构

本轮使用 Apple M1 Pro、16 GiB RAM、macOS arm64、Python 3.11，CPU 推理。原生依赖为 `sherpa-onnx 1.13.8+smartvoice.whisper2`。实际个人配置为每实例四线程、最少一个/最多两个实例、模型等待容量二、等待预算 60 秒、执行预算 600 秒、允许不同模型并行。测试复制配置到独立临时目录，使用只读安装模型资产和自有回环 TCP 服务，未改写个人配置。

生产窗口仍是 Whisper Base 25 秒、其他模型 15 秒，所有切点重叠一秒。STT 25 MiB/600 秒、TTS 4000 字符/180 秒、默认 MP3 等限制保持不变。本轮不包括 Qwen3-TTS 长文本优化。

内部阶段诊断通过通用 port 和上下文开关实现，音频/推理 adapter、运行时队列和服务分别记录自己的职责。嵌套阶段扣除子阶段时间，不把初始化、原生推理重复计入外层。公共 HTTP 请求、响应与能力默认值未增加诊断字段。窗口计数与成功 adapter 调用数核对；报告中兼容保留的 `native_calls` 指该调用数，真正原生解码次数取 `native_inference.calls`，纯数字静音可绕过解码。

新增正确性修复：同步推理返回前，取消异步包装任务也不能提前归还传输队列容量；LID 只对声明的可恢复推理/模型不可用错误降级，过载、超时、取消与未知错误向外传播。增加相应确定性测试。

按有完整标注、满足时长且可下载的录音 ID 排序选择。来源、原文件及切片 SHA256、标注校验和保存在本地清单 `sandbox/stt-continuous/manifest.json`。保留自然停顿、噪声及重叠说话。

AISHELL-4 参考从 TextGrid 词汇区间提取，移除非词汇标记；AMI 按时间合并所有说话者的单词，排除标点。截取终点按标注中点选入参考；跨终点区间单独计数，不宣称已人工校准部分词句。重复表达保留。CER/WER 使用此前的大小写和标点归一化，不转换数字写法或繁简体。重叠说话时长单独统计；缺少可靠逐词对齐时，不能给出独立重叠区域错误率。

许可分别是 [AISHELL-4 CC BY-SA 4.0](https://www.openslr.org/111/) 和 [AMI CC BY 4.0](https://groups.inf.ed.ac.uk/ami/download/)。AMI 标注归档 SHA256 为 `b56e5babb2496b8795deeeda7e71178d7fbc9963f94276cf2a3f4b56ebbc9f9d`。语料准备是显式下载操作；CI 和产品启动不下载。

每种语言只有两份录音，三种时长共享前缀；三轮重复是运行重复，不能当作新的独立语料。另保留 FLEURS 每语言十份自然语音构成的中文/英文/混合拼接基线；混合输入明确标为拼接样本。所有模型结果文件默认只保存分数、长度、窗口和阶段测量，不保存完整转写。

### SenseVoice HTTP 与异常路径

自有真实 TCP 服务完成二十五项矩阵检查：二十四次成功处理及一次 601 秒超限拒绝。覆盖直接 SenseVoice 的中英文、显式语言/auto、WAV/MP3、8/25.02/70/75/300/590/600 秒，自动路由以及历史时长匹配 MP3。路由测试保留实际配置，报告记录实际选择的模型，不能把路由到其他模型的请求计为直接 SenseVoice 验证。

损坏音频为 422，上传超限为 413，Supertonic 的 MP3/WAV 兼容检查通过。执行超时为 504，响应返回时仍有一个原生租约在运行，直到原生调用返回才最终释放；只启动了十一段。断连路径只启动三段。两者均确认不再启动后续窗口并最终排空。

五十七个音频/上传 spools 中三十三个落盘，结束时未关闭数为零；自有服务器停止且临时状态目录删除。传输层队列满/等待超时、模型层队列满/等待超时四项实际 SenseVoice 检查均为预期 503，拒绝请求未进入原生推理，恢复请求成功。

阶段示例：已预热的 600 秒中文 MP3 请求耗时 10.670 秒，六十二次窗口调用、六十二次原生解码，覆盖结束为 600.000 秒。解码 0.330 秒、原生输入准备 0.360 秒、原生推理 9.103 秒、合并 0.016 秒，模型排队合计 0.0006 秒；直接显式语言路径没有 LID。此例为重复短语音构成的合成输入，只用于处理与阶段耗时验证。各阶段是互斥测量，但没有覆盖所有文件校验和框架开销，不能强行相加为完整 HTTP 时间。

二十请求筛选通过未能保证五百请求稳定。三组推荐门槛均失败：同模型 RSS 比为 1.147；不同模型 P95 比为 1.267 且存在失败；TTS 存在失败且候选等待趋势不稳定。所有后台长请求均成功并最终排空，不提高队列或并发默认值。较低到达率诊断与正式确认分开保存。

随后仅对当前策略补做各一百个短请求的低负载诊断：Qwen3-ASR 到达间隔 1.6 秒，成功率 100%、P95 745.2 毫秒；Supertonic 到达间隔 0.8 秒，成功率 100%、P95 652.7 毫秒。两组等待趋势稳定、后台成功并最终排空。结果支持负载压力与拒绝有关，但没有五百请求及候选配对证据，不能作为推荐负载或配置门槛通过。

五轮同进程加载、长请求、504 超时、TCP 断连、恢复和关闭已完成。每轮 runtime 弱引用剩余数均为零、十个 spool 全部关闭、临时状态目录删除、租约及等待队列最终归零。关闭后的 RSS 为 686.4、875.1、915.3、957.5、911.3 MiB：前四轮增加、第五轮下降；不能据此宣称原生内存全部释放或已经证明无泄漏。保留趋势作为后续 allocator/原生缓存定位依据。

单实例对照单独标为二十请求探索性测量，不计为五百请求正式门槛。最终完整回归使用显式 `--stt-models stt-sensevoice-small-int8`，不能称为全模型完整回归；不带该参数的全模型前置条件和测试范围保持不变。

单实例同模型当前/候选 P95 为 356.9/411.1 毫秒，成功率为 100%/95%；与生产双实例对照的样本量不同，不能计算正式配置优劣。不同模型和 TTS 的探索性结果也没有取得正式推荐资格，保留双实例默认。

最终代码已执行：CI **214/214**、SenseVoice 范围默认真实回归 **240/240**、SenseVoice 范围完整长音频回归 **244/244**，全部通过。完整模式包含 300/590 秒中英文检查；没有缺少必需模型而跳过的项目。现有 TTS 与路由兼容检查仍执行，不把路由选到其他 STT 的结果计为该模型完整回归。未经范围筛选的全 STT 模型回归本轮未执行。

## 验收限制与推荐原则

完成运行仅说明实验结束。候选推荐还要求每语言及连续/拼接分组错误率均不退化、没有新增已核对的边界漏字或重复误删，并通过短请求 P95、长请求耗时、峰值 RSS、执行预算和排队稳定门槛。未经验证不调整生产默认值。

人工试听边界、数字、人名及合法重复表达仍待完成。原生逐窗输出与合并结果分别计分，用于区分合并损失与原生识别问题。Whisper 原生解码专项定位按用户要求暂缓。

固定到达率测试的 RSS 包含同进程的服务器和探测客户端，不能当作服务器独占内存。RSS 未回到初始值不能单独证明泄漏；对象/租约释放和持续增长趋势分别判定。

本轮建议：保留 SenseVoice 十五秒窗口、全部边界一秒重叠和当前实例/预算。主体处理、异常传播与资源所有权的自动化检查已完成；候选不晋升。后续首先人工核对连续语音边界及拼接中文退化样本，再定位原生 RSS 滞留并开展至少五百请求的较低负载配对确认。Whisper 优化与原问题 MP3 质量验收继续单独列为暂缓/前置条件不足。
