# SenseVoice 切分退化定位与边界评审包

日期：2026-10-04。范围：SenseVoice；Whisper 优化继续暂缓。生产窗口、并发、长度与超时默认不变。

## 本轮做了什么

新增显式验证工具 `scripts/validate_speech.py sensevoice-boundaries`。使用音频 adapter 已有的实验参数，穷举相对静音阈值、最小八秒窗口、仅强制切点重叠三个因素的八种组合，每种使用独立进程。

每轮七个输入：AISHELL-4 和 AMI 各两份 75 秒连续前缀，加 FLEURS 中文、英文和混合拼接控制，共五十六次诊断请求。另重跑当前/候选各七次请求生成最终试听包。该诊断没有重跑全部 300/590 秒输入，也不替代此前三轮正式质量验收。

通过正式路由的 TestClient 入口运行，直接选 SenseVoice；逐窗原生结果在内存中捕获，并用产品合并函数重放，逐条核对与实际响应一致。窗口数量、覆盖到末尾、实例及传输队列排空、临时 spools 关闭和独立状态目录删除均检查。生产服务仍不按模型名称分支。

默认报告只保存错误数、编辑位置、窗口和阶段测量。`--review-dir` 显式启用局部音频及有长度上限的文字评审材料；不写入产品默认日志。

## 八种组合结果

归一化沿用此前规则，不改变数字、缩写或繁简体。连续语音这里只统计四份 75 秒前缀，不能直接与此前 75/300/590 秒合并指标比较。

| 策略 | 连续中文 CER | 连续英文 WER | 拼接中文 CER | 拼接英文 WER | 混合拼接 CER |
| --- | ---: | ---: | ---: | ---: | ---: |
| 当前 | 31.75% | 28.40% | 6.09% | 10.94% | 10.78% |
| 仅相对阈值 | 30.75% | 33.46% | 5.45% | 8.33% | 12.44% |
| 仅最小八秒 | 32.50% | 30.35% | 8.33% | 11.98% | 8.62% |
| 仅强制切点重叠 | 27.50% | 29.57% | 4.49% | 12.50% | 12.94% |
| 相对阈值＋八秒 | 30.75% | 29.18% | 5.77% | 8.33% | 4.15% |
| 相对阈值＋强制重叠 | 30.75% | 27.24% | 4.17% | 7.29% | 14.43% |
| 八秒＋强制重叠 | 27.00% | 29.96% | 6.41% | 16.67% | 13.18% |
| 原候选（三项同时） | 30.75% | 29.18% | 6.41% | 8.85% | 6.05% |

中文拼接参考为 312 字符：当前十九个错误，候选二十个，复现了此前退化。仅最小八秒为二十六个错误；仅相对阈值为十七个；仅强制重叠为十四个。参数之间存在交互，不能把单个指标改善推广到其他分组。八种组合中没有新的策略满足所有五个分组均不退化。

## 错误定位与合并归因

候选相对当前新增的对齐错误集中在三份原始录音：

| 原始录音 | 新增差异 | 定位 |
| --- | --- | --- |
| `zh_00_clean` | “宣誓就职”中的三个字被识别成“示旧治” | 归一化输出交界附近 |
| `zh_03_clean` | “同理”漏字 | 归一化输出交界处 |
| `zh_05_clean` | `METI` 的字母差异 | 窗口内部，不能归为边界漏字 |

这些是机器编辑对齐定位，合法重复表达可能有多种最短对齐；不是人工结论或词级时间戳。新增错误与修正错误同时存在，因此候选总错误数只增加一，而非只出现一个新错字。

当前逐窗直接拼接为二十四个错误，合并后十九个；候选逐窗拼接为二十七个，合并后二十个。候选首次去重发生在输出第 193 个归一化字符附近，上述新增错误的输出位置在 28–155 之间。此次数据没有显示该次去重造成这些新增错误，现有证据更支持切分改变识别上下文；不能因此宣称去重对所有样本都安全。

不根据这些结果改写共享合并函数，也不直接应用最小八秒或强制重叠策略。保留 SenseVoice 十五秒、所有切点一秒重叠默认。

## 试听材料与人工验收

本地 `sandbox/stt-boundary-review/review.md` 提供当前/候选共六十五处切点、每处前后三秒的音频，以及三份新增错误录音的优先评审入口。目录共七十八份 WAV，包含原始录音错误定位材料。中英文连续边界只覆盖四份 75 秒输入，长输入后部边界仍未覆盖。

每处列出切点、实际重叠、有长度上限的前窗末尾/后窗开头文字和参考区间上下文。参考是整段标注或原始录音上下文，不能视为六秒片段的逐字稿。所有 `human_verdict` 保持 `pending`。

人工依次核对：

1. 两个新增交界错误是否与切分处的语音上下文有关。
2. 数字与英文缩写是识别错误还是写法不同；正式 CER/WER 归一化规则暂不调整。
3. 连续语音的弱音、自然停顿和重叠说话是否出现漏字。
4. 重复表达是否被合法保留，或被去重误删。

样本授权与来源同此前连续语音清单：FLEURS/AMI 为 CC BY 4.0，AISHELL-4 为 CC BY-SA 4.0。试听包 README 保存来源、修改方式和分享要求。

## 后续顺序

后续更新：依据用户“先假设人工通过”的实验授权，已对保留全部切点重叠的 `relative-minimum8` 候选重跑完整 75/300/590 秒三轮比较。下文“当前八种组合都存在退化”描述的是此页七输入诊断，不能代替完整分组门槛。新结果和资源验收见 [新候选验证](stt-sensevoice-v2-validation.md)；旧试听包与人工状态保持原记录。

先完成人工边界评审，再针对确认的问题设计有声学上下文依据的候选。候选需要完整连续语音三轮质量比较通过后，才进入至少五百请求的稳定负载配对和服务器独立 RSS 验证。当前八种组合都存在质量退化，不继续投入正式晋升测试，也不提高实例、排队、长度或超时默认值。

原问题 MP3 已由用户确认身份，当前 SenseVoice 与 Qwen3-ASR 的完整 HTTP 处理也已通过；Whisper 当前代码复测仍受本机缺少模型资产限制。历史 Whisper 参考文本没有固定在元数据报告中，质量指标复现仍待处理。全模型完整回归不属于本轮 SenseVoice 范围。MP3 最新记录见 [STT 过载与边界验证](stt-admission-boundary-validation.md)，连续语音历史证据详见 [连续语音验收报告](stt-continuous-acceptance-validation.md)。
