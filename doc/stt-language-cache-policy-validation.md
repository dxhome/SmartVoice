# STT 分段语言、缓存与窗口策略验证

后续的真人单条对照、保守时间戳合并与混合任务实验见 [补充验证](stt-interaction-alignment-validation.md)。以下保留上一阶段的结果。

日期：2026-10-04。本机 macOS / Apple Silicon / CPU，sherpa-onnx `1.13.8+smartvoice.whisper2`。

## 已实施

- 具体模型 + auto 的每个窗口都使用 auto，服务不再根据首段固定后续语言。所有窗口报告同一种支持的语言才返回该语言；不同或未知则返回 null。这是模型报告的汇总，不是实际输入为单语的证明。
- smartvoice-auto + auto 保留一次 LID 和本次请求的固定路由语言；显式语言保持逐段一致。
- Qwen3-ASR 不按语言重复初始化：其原生构造参数没有语言选项，同一 adapter 内的同一模型在中文、英语、auto 间复用 recognizer。SenseVoice/Whisper 的初始化包含语言，保留相应区分。共享服务没有模型名称分支。
- 保留有原生结束时间且跨入新增音频的时间戳片段；已完全处于重叠区的片段仍可剔除。只有起点的原生 token 尚不能可靠判断跨边界时长，仍是待改进项，不生成估计结束时间。
- 文本对齐保留原字符串偏移，仅比较时 casefold，避免 Unicode 大小写转换改变长度后误切。保存的匹配对象限定为前后各 8 个词元；没有加入模糊去重。合法重复与更长重叠仍需进一步质量评估。
- 为音频 adapter 增加仅强制切点重叠的实验选项，覆盖静音/强制切点与有限终止测试。正式组装仍使用所有切点重叠；未推广实验策略。

## 回归

CI 183 项通过，默认回归 239 项通过。新增检查覆盖逐段 auto、混合/未知语言的 nullable 汇总、一次 LID 的固定路由语言、Qwen 语言无关复用、其他模型语言相关缓存、跨边界时间戳及 Unicode 原字符串偏移。

断连测试用 finally 中的事件显式释放模拟原生调用，避免强制 GC 的耗时触发测试的 5 秒自动释放，造成租约断言失真。

改动后的真实 TCP HTTP 矩阵再次通过：三种 STT 的 600 秒中文 MP3 分别耗时约 10.70、41.70、72.72 秒；分段与成功原生调用数仍分别为 62、36、62。20 条成功路径、601 秒拒绝、损坏文件、Supertonic MP3/WAV、截止时间和断连检查全部通过，队列与实例最终归零，自有服务器已关闭。客户端断连本轮发生在原生调用开始前，未启动任何原生分段；租约持有行为由截止时间检查和确定性阻塞测试覆盖。

本轮混合测试进程累计峰值约 3433 MiB，上一轮约 3594 MiB。不同运行的缓存、分配器和时序有差异，不能把差值归因于缓存优化，仍需按模型测量冷启动、语言切换和回收后的内存。

## 真人样本策略比较

使用本地 FLEURS 固定 revision `d16ac437ac42fb543bf2893b934dac1af970e361` 的 test split：4 条中文和 4 条英语 clean 样本，读取前校验 SHA256。来源、CC BY 4.0 和身份信息保留在 `sandbox/streaming/data/real.manifest.json`；署名为 Google / Conneau et al. (2022)。实验在句间加入 0.3 秒静音，中文合并为 39.26 秒、英语 39.92 秒，交替拼接的混合输入为 79.18 秒。

比较 15 秒所有切点重叠、25 秒所有切点重叠、25 秒仅强制切点重叠。每轮 3 模型 × 3 策略 × 3 输入 = 27 请求，全部成功；独立顺序复测的质量分数与首轮完全一致。各模型单独创建测试环境；不持久化窗口覆盖，也不改变正式能力配置。

| 模型 | 策略 | 中文 CER | 英语 WER | 混合 CER |
|---|---|---:|---:|---:|
| SenseVoice | 15 秒全重叠 | 4.42% | 9.86% | 12.05% |
| SenseVoice | 25 秒全重叠 | 7.96% | 8.45% | 15.86% |
| SenseVoice | 25 秒仅强制重叠 | 4.42% | 8.45% | 23.89% |
| Whisper | 15 秒全重叠 | 36.28% | 28.17% | 48.63% |
| Whisper | 25 秒全重叠 | 67.26% | 9.86% | 63.64% |
| Whisper | 25 秒仅强制重叠 | 30.09% | 9.86% | 87.95% |
| Qwen3-ASR | 15 秒全重叠 | 3.54% | 21.13% | 8.03% |
| Qwen3-ASR | 25 秒全重叠 | 6.19% | 8.45% | 22.20% |
| Qwen3-ASR | 25 秒仅强制重叠 | 2.65% | 8.45% | 19.24% |

归一化仅去标点、统一大小写和空白，不转换繁简、数字、同音字或专名。混合 CER 对中英文字符一并计数，不能与单语 CER/WER直接比较。样本量很小，不能将结果作为模型排名、正式准确率验收或推广默认配置的依据。

**决策：保留当前默认配置。** 较长窗口减少段数，却未同时改善单语和混合质量；仅强制重叠也未稳定改善。Whisper 的漏字/混合识别问题仍需独立分析，无法仅靠本轮策略切换解决。某些 mixed 请求仍返回 zh，说明模型各窗可能一致报告主要语言，服务不能据此判断音频真实为单语。

真实跟踪验证 Qwen3-ASR 在整个中文、英语、auto 矩阵仅初始化一次 recognizer；SenseVoice 和 Whisper 各初始化三个语言配置。这个证据证明去除了等价初始化，不代表跨模型并发容量或内存下降比例。

另有 3 个旧行为对照请求，在当前默认窗口下仅重建“首段检测后固定语言”的原生调用序列，比较识别正文：

| 模型 | 旧首段固定语言：混合 CER | 新逐段 auto：混合 CER |
|---|---:|---:|
| SenseVoice（15 秒） | 11.84% | 12.05% |
| Whisper（25 秒） | 87.32% | 63.64% |
| Qwen3-ASR（15 秒） | 8.03% | 8.03% |

Whisper 本样本有改善但仍存在明显质量问题；SenseVoice 增加一个字符错误，不能宣称逐段 auto 对所有模型提升准确率。Qwen 未报告首段语言时旧逻辑也不固定语言，因此正文未变。调整的明确收益是请求语义不被服务隐式改写、汇总不把未知段当作已知单语，以及避免等价 native 初始化。
