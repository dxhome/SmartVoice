# SmartVoice v0.2.2

SmartVoice v0.2.2 improves model availability refresh while the service is running and updates model concurrency benchmark coverage.

## Highlights

- Share one verified installed-model snapshot across model discovery, runtime status, and capability reporting.
- Refresh stale model availability in the background while keeping the last successful snapshot available to requests.
- Retry failed background refreshes and allow users to request a refresh with the CLI or API.
- Automatically refresh model availability after install, import, or removal operations.
- Improve the fixed-arrival concurrency benchmark workflow and publish updated per-model results.

## Installation

```bash
python -m pip install --upgrade smartvoice
```

Model weights remain separate from the package. Install or update models with `python -m smartvoice models install <model-id>`.
