# SmartVoice v0.2.0

SmartVoice v0.2.0 adds native CPU inference for Qwen3-TTS and expands model availability across supported desktop platforms.

## Highlights

- Add the Qwen3-TTS 0.6B CustomVoice model with a native INT8 runtime on macOS Apple Silicon and Windows x64.
- Build platform-specific PyPI wheels that bundle the matching runtime, alongside a source distribution.
- Expand model catalog and language-aware routing for Whisper, SenseVoice, Qwen3-ASR, Kokoro, Matcha Baker, Supertonic, and Qwen3-TTS.
- Improve model installation, verification, local state tracking, and Windows deployment behavior.
- Expand regression coverage with a direct real-inference smoke test for every installed, runtime-available catalog model.

## Installation

Install SmartVoice and the inference dependencies with:

```bash
python -m pip install "smartvoice[inference]"
```

Model weights are downloaded separately. Install a model with `python -m smartvoice models install <model-id>`; see the [model catalog](https://github.com/dxhome/SmartVoice#model-catalog) for supported models and languages.

Qwen3-TTS is available on macOS Apple Silicon and Windows x64 platform wheels. Windows distribution includes the runtime DLLs and their license notices.
