# SmartVoice v0.2.1

SmartVoice v0.2.1 adds Linux x86_64 release wheels and improves cross-platform packaging, runtime reporting, and regression coverage.

## Highlights

- Publish a Linux x86_64 wheel that bundles the native Qwen3-TTS runtime, alongside the macOS Apple Silicon and Windows x64 wheels.
- Include the Linux Qwen3-TTS builder and native fingerprint helper in source distributions.
- Install inference runtimes as default project dependencies so `pip install smartvoice` includes local inference support.
- Improve Linux host metrics, CLI behavior, and Sherpa provider compatibility checks.
- Expand CI and regression coverage for Linux packaging and platform behavior.
- Update platform guidance and installation documentation to reflect Linux x86_64 support validated on Ubuntu 26.04.

## Installation

```bash
python -m pip install --upgrade smartvoice
```

Linux x86_64 wheels are built on Ubuntu 24.04 and dynamically link to system OpenBLAS. Install `libopenblas0` on Ubuntu before using the wheel. Linux x86_64 clean installation and model-backed inference have been validated on Ubuntu 26.04. Other Linux distributions, older glibc releases, Linux ARM64, and CPUs without compatible native runtime instructions are not verified.

Model weights are downloaded separately. Install a model with `python -m smartvoice models install <model-id>`; see the [model catalog](https://github.com/dxhome/SmartVoice#model-catalog) for supported models and languages.
