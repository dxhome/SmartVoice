# Whisper 中文漏字与窗口截断修复

日期：2026-10-04。验证环境：本机 macOS / Apple Silicon / Python 3.11 / CPU，每实例 2 个线程。

## 原因与改动

1. sherpa-onnx 1.13.8 对每个 Whisper 字节级 BPE token 单独做 UTF-8 清理，删除跨 token 的中文字节。修复为先拼接完整文本，再清理和规范化。该修复对应上游 [PR #3965](https://github.com/k2-fsa/sherpa-onnx/pull/3965)。
2. 上游 greedy decoder 的每秒 6 token 固定预算会截断快速中文；直接移除上限又可能在静音输入后重复生成很长文本。本地补丁按每秒 12 token 分配预算，同时受剩余模型文本上下文限制；仍以 EOT 或预算上限结束。
3. 本样本上 15 秒窗口仍存在提前 EOT，Whisper Base 改为目录声明的 25 秒窗口；其余模型默认 15 秒。Service 消费通用 `SegmentPlanning` 能力，不识别具体模型名。保留每个切点 1 秒重叠。
4. 未产生时间戳时不读取原生 token 字符串，避免 Python 对单个不完整 UTF-8 token 转换报错。未添加虚构时间戳。

修复只回移到固定的上游 v1.13.8 源码 `11afbd009a7f8c08f4bcf2fc1b265d0df4670fbf`，没有使用整个上游开发分支。原始模型和 token 文件不修改。

## 构建与使用

修复位于原生依赖，单独更新 Python 产品代码不能消除引擎漏字。目前正式 PyPI 1.13.8 不含该修复。构建脚本不会自动安装或修改用户环境：

```sh
.venv/bin/python scripts/build_sherpa_whisper_fix.py --output wheels --jobs 2
.venv/bin/python -m pip install --no-deps --force-reinstall wheels/sherpa_onnx-1.13.8+smartvoice.whisper2-*.whl
```

构建需要 Git、CMake、C++ 编译工具及网络，用于获取固定源码和构建依赖；正常服务启动不下载或构建。脚本校验源码完整 revision，应用补丁前检查匹配。本地包版本为 `1.13.8+smartvoice.whisper2`。whisper2 使用 12 token/秒输出预算；whisper1 的无界预算曾在短英文样本上重复输出 “If”，因此不再作为回归运行版本。

本机 `.venv` 已安装修复包；已启动的服务需要重启才会加载。wheel 保存在被 Git 忽略的 `wheels/`，不能依赖该目录在其他机器自动存在。重新安装正式 1.13.8 会丢失修复；其他平台需重新构建并验证。

本次 wheel SHA256：`f247eb760398462d7e8a167f46aea1774623abe3de5cdbffc73127b3f53e5c1c`。验证过 wheel 脱离原生构建目录仍能导入，避免依赖临时构建目录。

## 样本与验证结果

输入为用户提供的中文电影解说 MP3，真实解码时长 53.5684375 秒；参考文本由用户提供。仅用于本次显式调试，默认业务日志没有新增音频或全文记录。

- 原始 15 秒策略出现大量单字缺失和窗口后半段遗漏；10 秒和 25 秒窗口单独调整也不能解决字节丢失。
- 单独改变尾部填充 300 → 1000 / 1500 未解决两个原生问题。
- 原生组合补丁配合 25 秒能力配置，通过真实本地 TCP HTTP 服务验证了具体 Whisper 模型的 `zh` 和 `auto` 请求；两者均返回 200、3 个窗口、53.568 秒，并识别到末尾“于是科部决定”。本次请求实际耗时分别为 10.25 秒和 10.07 秒；请求结束后实例池活跃和等待数均为零，测试服务器已关闭。
- 修复后恢复了“剧情全程一环套一环”“内心深处的秘密”“只是一个梦境”等此前缺失的内容。
- 原始 15 秒输出对用户参考的 CER 约 49.24%；修复后 25 秒完整 API 输出约 32.11%。计算只去除标点并统一拉丁字母大小写，未做繁简转换；繁体、同音字和参考中的专名写法也计入错误。该指标不是跨模型结论。
- 相关确定性与契约测试 39 项、模型目录测试 14 项，共 53 项通过。
- 修复包下 Supertonic 的 MP3、WAV 请求均成功；SenseVoice 的 16 秒合成音频走 2 段并成功返回，仅验证原生兼容与分段通路，不代表真实语音质量回归。

## 验证边界与后续工作

这份样本仍有同音字、专名错误、繁简体混合及重叠处重复，没有通过逐字完整验收。识别到结尾、字符数量接近参考、或返回成功均不能证明准确率达标。

本次没有完成所有语言、所有 STT 模型、600 秒真实旁白和并发容量回归；本机结果不能证明其他平台的原生包可用。后续应独立处理重叠对齐与质量评估，并在上游正式发布包含 UTF-8 和输出预算修复的版本后重新验证替换本地补丁的可行性。
